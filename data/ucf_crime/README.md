# UCF-Crime Dataset

Directory structure expected by the pipeline scripts:

```
data/ucf_crime/
├── train/                      # Training split
│   ├── Normal/                 # Normal surveillance videos
│   ├── Abuse/
│   ├── Arrest/
│   ├── Arson/
│   ├── Assault/
│   ├── Burglary/
│   ├── Explosion/
│   ├── Fighting/
│   ├── RoadAccidents/
│   ├── Robbery/
│   ├── Shooting/
│   ├── Shoplifting/
│   ├── Stealing/
│   └── Vandalism/
├── test/                       # Test split (same subfolders)
├── clips/                      # Segmented 10s clips
│   ├── train/
│   └── test/
├── meta/                       # Train/test split lists
├── embeddings/
├── evaluation/                 # Evaluation results
├── clip_manifest.json          # Generated by segment_videos.py
├── embeddings_cloud.npz        # VideoMAE embeddings (768-dim)
├── embeddings_cloud_meta.json
├── embeddings_edge.npz         # MobileNet embeddings (576-dim)
├── embeddings_edge_meta.json
└── qdrant_edge/                # Local Qdrant storage (edge mode)
```

## Pipeline

1. `uv run scripts/download_ucf_crime.py` - Download and organize videos
2. `uv run scripts/segment_videos.py` - Segment into 10s clips
3. `uv run scripts/embed_clips.py --model cloud` - Extract embeddings
4. `uv run scripts/index_qdrant.py --mode cloud` - Index into Qdrant
5. `uv run scripts/simulate_cameras.py` - Demo simulation
6. `uv run scripts/evaluate.py` - Run evaluation
